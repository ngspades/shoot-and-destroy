# ngspades-client

Public issues and roadmap of ngspades-client, the game client of the ngspades project. The code lives in a private repository.

- [Client checklist](docs/client-checklist/) (published at https://ngspades.github.io/shoot-and-destroy/): a numbered, testable list of requirements for writing a client of Ace of Spades 0.75/0.76, the community's 0.75 extensions and protocol 1.0, with a conformance matrix for ngspades-client.
- [Protocol documentation](https://ngspades.github.io/protocol/)
- [ngspades-server](https://github.com/ngspades/server)
